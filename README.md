# Which iSWAB kit fits your study?

An independent concept for a customer-facing kit selector for Mawi DNA Technologies' iSWAB portfolio. You describe what you're analyzing, the sample type, the downstream assay, the DNA you need per sample and how many days samples sit at room temperature. The tool matches the study to an existing iSWAB kit and shows each check against Mawi's published specs.

- Nine kits: iSWAB-Discovery, DNA-250, DNA-1200, ID, Animal, RNA-v2, Cells, Microbiome and Microbiome with FecesCatcher
- Uses only figures from Mawi's own product pages (read 10 Nov 2026), all linked under Sources on the page
- No performance claims and no comparisons with other companies' kits. In the USA, Mawi designates these kits For Research Use Only.

**Live site:** https://vaishanavi04saware-stack.github.io/Kit-Comparison-Tool/

## Files
- `index.html`: page structure
- `style.css`: styles, in light and dark themes
- `app.js`: kit data and selection logic
- `DESIGN.md`: design tokens taken from mawidna.com (aligned with the brand, not copied: no logo or font files)
